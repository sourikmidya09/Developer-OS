# ⚡ Developer OS

> **The workspace I wish I had while learning Computer Science.**

Developer OS is an all-in-one productivity and learning platform designed specifically for aspiring developers and students. Instead of juggling multiple apps for coding practice, project tracking, note-taking, and focus sessions, Developer OS brings everything together into one clean and intuitive workspace.

Built as a passion project by a 17-year-old student, this application reflects a simple idea:

> *Learning to code should feel organized, motivating, and less overwhelming.*

---

## 🌟 Why I Built This

As I explored programming and prepared for my future in Computer Science, I found myself switching between different tools:

- One app for projects,
- Another for coding notes,
- A website for DSA practice,
- A timer for focus sessions,
- And random documents to remember mistakes I had already solved.

I wanted a single place that could support my entire learning journey.

Developer OS was created to solve that problem.

---

## ✨ Features

### 📊 Dashboard
Get a quick overview of your growth and productivity.

- Total Projects
- Saved Snippets
- DSA Progress
- Debug Entries
- Focus Sessions

---

### 🚀 Project Dashboard

Track your personal projects in one place.

Features:
- Add, edit, and delete projects
- Progress tracking
- Technology tags
- GitHub links
- Demo links
- Project status management

---

### 📝 Snippet Vault

Save useful pieces of code for future use.

Features:
- Store code snippets
- Categorize by language
- Search instantly
- Edit and delete snippets
- Copy snippets quickly

---

### 🧠 DSA Tracker

Stay consistent with algorithm practice.

Categories include:

- Arrays
- Strings
- Linked Lists
- Trees
- Graphs
- Dynamic Programming
- Recursion

Features:
- Track solved problems
- Visual progress indicators
- Completion statistics

---

### 🐞 Debug Notebook

Turn mistakes into lessons.

Document:

- Errors encountered
- Why they happened
- How they were fixed
- What you learned

Over time, it becomes your personal debugging handbook.

---

### ⏱️ Focus Timer

A built-in Pomodoro timer to encourage deep work.

Features:
- Start
- Pause
- Reset
- Session counter
- Productivity encouragement

---
